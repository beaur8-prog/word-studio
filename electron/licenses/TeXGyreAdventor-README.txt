Word Studio use:
A local-only FontFace probe preserves each installed Century Gothic face.
Only an unavailable face receives this fallback. No system font is installed
or replaced. The original requested family and point size remain in native
and standard DOCX files; PDFs name the actual Adventor face used.

This is a compatible substitute, not the proprietary Century Gothic font.
The regular face matched 72 of 73 measured characters within 1/1000 em
in the frozen public Word sample. Slash is wider (513 versus 437 units
per 1000 em); parentheses differ by one unit. Shapes, other scripts and
kerning can still differ. Unsupported characters use platform fallback.

CSS ascent/descent overrides preserve the actual Word Century Gothic
normal line box. Four-face values were read from a newly rendered public
Word font/contextual policy probe on 2026-11-04 UTC:
regular and italic: ascent 1989 / 2048
bold: ascent 2032 / 2048
bold italic: ascent 2060 / 2048
all four: descent 451 / 2048; hhea line gap 0
No proprietary font program or glyph outline is redistributed.
Restart the app after installing an original system face so its local probe
can select the newly installed face.
