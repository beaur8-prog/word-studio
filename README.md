# Word Studio

Windows·macOS·Linux용 로컬 문서 편집기입니다. 한국어 리본, 서식 편집, 표·그림·메모, DOCX 변환과 PDF 출력을 제공합니다. Microsoft Word의 화면과 배포 파일 구조를 관찰해 독립적으로 구현했습니다.

일반 사용자는 [최신 릴리즈](https://github.com/beaur8-prog/word-studio/releases/latest)에서 앱을 내려받으세요. [다운로드·설치·사용 안내와 버전별 변경 내역](USER_GUIDE.md)에 Mac·Windows·Linux의 설치, 실행, 업데이트 방법을 정리했습니다.

> **다운로드와 첫 설치·실행 시 보안 경고가 나타날 수 있습니다.** Mac 배포본은 Apple Developer ID 서명·공증을 받지 않았고, Windows 설치 파일과 앱은 코드 서명을 받지 않았습니다. 다운로드 중 브라우저에서 위험한 파일이라는 경고가, Mac에서는 개발자 확인 또는 실행 차단 안내가, Windows에서는 SmartScreen 또는 알 수 없는 게시자 경고가 나타날 수 있습니다. **‘Windows의 PC 보호’** 화면에서는 출처와 파일을 확인하고 실행하기로 했다면 **‘추가 정보’ → ‘실행’** 순서로 진행합니다. 경고 문구와 실행 허용 여부는 브라우저·운영체제·보안 설정·조직 정책에 따라 다릅니다. 자세한 내용은 [설치·실행 안내](USER_GUIDE.md)를 참고하세요.

## 실행

Node.js 22.12 이상이 필요합니다. 저장소를 내려받은 폴더에서 실행하세요.

```powershell
npm ci
npm run build
npm start
```

브라우저 개발 모드는 `npm run dev`로 실행하며 주소는 `http://127.0.0.1:5191`입니다. 개발 중 데스크톱 앱은 별도 터미널에서 `npm start -- --dev`로 엽니다.

```powershell
npm run package:win
```

Windows x64 앱을 `release/windows/Word Studio`에 만든 뒤 NSIS 설치 마법사 `release/installer/Word-Studio-1.3.0-windows-x64-setup.exe`를 생성합니다. 공식 Electron 런타임의 체크섬을 검증한 후 전용 아이콘을 적용한 앱을 설치 파일에 넣습니다. 설치 화면은 한국어·영어, 현재 사용자용 설치, 경로 선택, 바탕 화면·시작 메뉴 바로 가기와 제거를 지원합니다. 설치 후 실행에는 Node.js, Office 또는 인터넷 연결이 필요하지 않습니다.

`npm run package:win:dir`은 앱 폴더만, `npm run package:win:setup`은 이미 만든 앱 폴더로 설치 파일만 생성합니다. 설치 파일 빌드와 실제 설치·재설치·제거 시험은 Windows GitHub Actions에서 수행합니다. 빌드 설정은 [electron-builder.config.cjs](electron-builder.config.cjs), 격리된 CI 시험은 [scripts/test-windows-installer.ps1](scripts/test-windows-installer.ps1)에 있습니다. NSIS 옵션은 [electron-builder 공식 문서](https://www.electron.build/docs/nsis/)를 따릅니다. 설치·재설치·제거는 `%APPDATA%\Word Studio` 복구 데이터와 사용자가 저장한 문서를 지우지 않습니다.

Mac에서는 `npm run package:mac`으로 기존 파란 문서·연필 아이콘을 적용한 `Word Studio.app`을 만듭니다. 검증된 앱은 `~/Library/Caches/WordStudioBuild/Word Studio.app`, 배포 ZIP은 `release/Word-Studio-mac-arm64.zip`(Intel Mac은 `x64`)에 생성됩니다. 앱을 응용 프로그램 폴더에 복사해 실행할 수 있습니다. 이 빌드는 로컬 사용을 위한 임시 서명이며 Apple 공증은 포함하지 않습니다. `npm start` 개발 실행에서도 같은 Dock 아이콘을 사용합니다.

## Linux 패키징

```sh
npm ci
npm run package:linux
```

Linux x64에서 `release/linux/Word-Studio-1.3.0-linux-x64.deb`를 만듭니다. 프로덕션 앱만 별도 디렉터리에 넣어 ASAR로 패키징하며, 앱 메뉴·아이콘과 `word-studio` 실행 명령을 제공합니다. Ubuntu 22.04에서 패키징하고 같은 DEB를 Ubuntu 22.04·24.04에서 설치·재설치·제거 및 실제 앱 실행으로 검증합니다. 빌드 설정은 [electron-builder.linux.cjs](electron-builder.linux.cjs), 격리된 CI 설치 시험은 [scripts/test-linux-package.cjs](scripts/test-linux-package.cjs)에 있습니다.

사용자는 다운로드 폴더에서 `sudo apt install ./Word-Studio-1.3.0-linux-x64.deb`로 설치하고 앱 메뉴 또는 `word-studio`로 실행합니다. 제거는 `sudo apt remove word-studio`입니다. 문서와 `~/.config/Word Studio/recovery`의 복구본은 유지됩니다. 자세한 설치·글꼴·업데이트 안내는 [사용 가이드](USER_GUIDE.md)를 참고하세요.

## 1.2.10 공식 DOCX 샘플 호환 수정

공식 샘플 20개에서 발견한 링크·표·상속 서식·번호 목록·VML 그림·구역 나눔 오류를 수정했습니다. 긴 다단 문서는 편집 화면에서도 다음 종이로 이어지며, 중앙 그림의 양쪽 공간과 원본 다각형 윤곽을 따라 텍스트를 배치합니다. 머리글/바닥글 안의 그림과 표, 각주/미주, 다단, 기호 글꼴과 구역별 편집 용지 폭도 보존합니다. Mac ZIP·Windows Setup·Linux DEB를 1.2.10으로 제공합니다. [수정·재검증 기록](OFFICIAL_SAMPLE_FIXES.md)을 참고하세요.

## 1.2.8 DOCX 표와 페이지 배치 개선

- 병합 셀의 좁은 격자, 백분율 음영·이중선·최소 행 높이와 중첩 표의 페이지 이동을 보완했습니다. 빈 부동 프레임 앵커가 빈 뒷장을 만들던 문제를 수정했습니다.
- 한글 줄간격·자간·공백을 보존하고 단순 EQ 겹침 필드의 원 안 글자 표시를 지원합니다. Windows에 설치된 돋움·굴림 계열의 윤곽선을 사용하며 Microsoft 글꼴 파일을 배포하지 않습니다.
- 1.2.6의 인라인 그림·탭·머리글/바닥글·복잡한 표 가져오기 개선과 1.2.5의 양식 배치 수정도 포함합니다. Mac의 오른쪽·가운데 탭 글꼴 측정 오류도 수정했습니다.
- [버전별 변경·설치 안내](USER_GUIDE.md), [Word 사용 사례와 호환성 차이](WORD_USE_CASES.md), [검증 기록](VALIDATION.md)을 참고하세요. 운영체제마다 설치된 글꼴이 달라 쪽수와 줄바꿈은 달라질 수 있습니다.

## 1.2.5 DOCX 양식 배치 보정

- 문서 기본값과 `basedOn` 문단·문자 스타일을 상속해 글꼴·크기·색을 가져옵니다. 빈 문단의 작은 글자 크기나 색이 셀 전체로 번지던 오류를 수정했습니다.
- 표의 원본 열 너비, 병합 셀의 열 배분, 표 들여쓰기, 기본 셀 여백과 테두리를 보존합니다. 문단 앞뒤 간격·오른쪽 들여쓰기·첫 줄/내어쓰기·자간과 명시적 페이지 나눔도 가져옵니다.
- 큰 한 셀 안에 문단과 중첩 표가 들어 있는 양식은 편집 화면과 출력에서 문단·행 경계로 나눕니다. 나눌 수 있는 양식 전체를 작은 글씨로 축소하지 않습니다.
- 기존에 변환된 복구본에는 누락된 원본 서식이 없으므로, **수정한 내용은 사본으로 저장한 뒤 원본 DOCX를 다시 여세요.** Word와 동일한 글꼴 측정·조판 엔진은 아니며 페이지 수와 세부 줄바꿈은 달라질 수 있습니다.

## 1.2.1 표 행 높이

표의 가로 경계선에 마우스를 올리면 높이 조절 커서와 파란 안내선이 나타납니다. 위아래로 드래그해 바로 위 행의 높이를 바꿀 수 있습니다. 마지막 행의 아래쪽 선과 세로로 병합된 셀의 아래쪽 선도 지원합니다. 열 너비 조절은 기존 세로선에서 그대로 사용합니다.

- 확대·축소 비율을 반영하며, 드래그 중 높이를 mm로 표시합니다.
- 마우스를 놓으면 한 번의 편집으로 저장되어 Ctrl+Z로 되돌릴 수 있습니다. Esc는 진행 중인 드래그를 취소하고, 경계선 더블클릭은 내용에 맞는 자동 높이로 되돌립니다.
- 높이는 내용을 가리지 않는 **최소 높이**입니다. 글자·여백보다 작게 줄이면 내용에 필요한 높이에서 멈춥니다. 읽기 모드에서는 조절되지 않습니다.
- 자체 파일·자동 복구·HTML·DOCX·PDF에 높이를 보존합니다. DOCX에는 최소 높이(`atLeast`)로 저장하며, 가져온 고정 높이도 내용이 잘리지 않도록 최소 높이로 처리합니다.

## 1.2.0 표 편집

여러 셀을 드래그하거나 첫 셀을 클릭한 뒤 Shift+클릭으로 범위를 선택하고 우클릭하세요. 키보드의 메뉴 키 또는 Shift+F10으로도 같은 메뉴를 엽니다. 선택 영역 안에서 우클릭하면 여러 셀 선택이 유지되며, 밖의 셀을 우클릭하면 해당 셀만 선택합니다.

- **글자·셀 서식**: 글꼴·크기, 굵게·기울임·밑줄·취소선, 글자색·배경색·형광펜 팔레트와 사용자 지정 색, 가로·세로 정렬, 줄 간격, 안쪽 여백, 서식 지우기.
- **테두리**: 실선·파선·점선·이중선, 0.5–6pt 굵기, 색상. 전체·바깥쪽·안쪽·방향별·가로·세로 적용과 제거를 지원합니다. 맞닿은 셀의 공유 선도 함께 갱신합니다.
- **표 편집**: 행·열·표 전체 선택, 행·열 삽입·삭제, 병합·병합 해제, 각 셀을 지정한 행·열로 나누기, 머리글 행 전환, 모든 열 너비 같게, 셀 내용 지우기, 표 삭제, 복사·잘라내기·붙여넣기.
- **보존**: 여러 셀의 기존 서식이 달라도 일괄 적용하며 실행 취소가 가능합니다. 자체 파일·HTML·DOCX·PDF에서 셀 배경·방향별 테두리·여백·세로 정렬을 보존합니다. DOCX의 직접 지정한 글꼴·크기·글자색과 빈 셀의 기본 글꼴도 가져옵니다.

메뉴 변경은 즉시 적용됩니다. 테두리는 선 종류·굵기·색을 고른 뒤 적용할 방향 버튼을 누르세요. ‘각 셀 나누기’는 선택한 각 셀을 나누고 원래 내용은 첫 조각에 둡니다. 주변 셀은 병합 범위를 조정해 내용을 유지합니다. 브라우저에서 클립보드 읽기 권한이 없으면 Ctrl+V를 사용하세요. Windows 앱의 붙여넣기는 기본 클립보드 동작을 사용합니다.

Word의 모든 표 기능을 재현한 것은 아닙니다. 표 스타일 갤러리, 자유로운 선 그리기·지우개, 대각선 테두리, 텍스트 방향 회전, 수식 계산, 표 주위 텍스트 배치와 내용을 잘라내는 고정 행 높이는 아직 지원하지 않습니다. 병합 셀 옆의 공유 선은 셀의 한 변 단위로 적용합니다.

## 1.1.0 개선

- **출력 미리보기**: 보기 → 인쇄 미리보기에서 PDF·인쇄에 사용하는 페이지를 확인합니다. 긴 문단은 문자 결합 단위를 보존하며 나누고, 표는 행 단위로 나누면서 머리행을 반복합니다. 미리보기와 PDF가 같은 페이지 트리를 사용합니다.
- **DOCX 보존**: 구역별 A4/Letter·세로/가로·머리글·바닥글과 방향별 여백을 가져오고 내보냅니다. 검토 메모의 위치·내용·해결 상태도 왕복 보존합니다. 같은 문장이 반복돼도 메모 위치를 텍스트 검색으로 추정하지 않습니다.
- **본문에 연결된 메모**: 본문 편집 시 메모 표시가 이동하고, 메모 창의 ‘본문으로 이동’으로 해당 범위를 선택할 수 있습니다.
- **파일 기반 복구**: 데스크톱에서는 사용자 데이터의 `recovery` 폴더에 원자적 파일 교체로 저장합니다. 문서마다 고유 ID를 사용하므로 제목이 같아도 분리됩니다. 직전 버전은 파일 메뉴에서 복사해 열 수 있습니다. 브라우저에서는 IndexedDB를 사용합니다.
- **종료 보호**: 자동 저장이 진행 중이거나 실패한 상태에서는 종료 확인을 표시합니다. 기존 localStorage 문서는 처음 실행할 때 복구 저장소로 이전합니다.

- 표 삽입, 행·열 추가/삭제, 셀 병합/분할, 열 너비 변경

- 어두운/밝은 화면, 눈금자, 40–200% 확대/축소

## 저장과 호환성

다른 문서를 열거나 새 문서를 만들 때 현재 문서의 복구 저장이 완료될 때까지 기다립니다. 저장에 실패하면 현재 문서를 유지하고 **파일로 저장 후 계속 / 저장하지 않고 계속 / 취소**를 표시합니다. 파일 저장을 취소하거나 실패한 경우에도 문서를 전환하지 않습니다. 다른 문서를 열면 실행 취소·다시 실행 기록을 초기화하며, 같은 문서를 파일로 저장할 때는 편집 기록을 유지합니다.

편집 상태의 백업에는 `.wordstudio` 형식을 사용하세요. 자동 저장은 현재 PC의 복구 수단이며 별도 파일 백업을 대체하지 않습니다. 최근 문서와 이전 정상 버전 목록에는 최근 20개 문서를 표시합니다. 복구 파일은 앱 사용자 데이터에 남습니다.

편집 화면의 페이지 배치는 블록 단위의 근사치입니다. **최종 출력 페이지는 인쇄 미리보기에서 확인하세요.** 서로 다른 구역의 용지 설정도 출력 미리보기에 적용됩니다. 한 페이지보다 큰 병합 셀 묶음·목록 항목·그림은 잘리지 않게 축소하며 미리보기에 안내를 표시합니다. Word와 동일한 조판 알고리즘이나 완전한 WYSIWYG 편집을 제공하지는 않습니다.

DOCX 가져오기에는 Mammoth를 사용합니다. 모든 글꼴·스타일 속성, 도형·텍스트 상자, 머리글·바닥글 내부의 복잡한 개체·서식과 필드, 변경 내용 추적, 매크로와 수식을 완전히 재현하지 않습니다. 연속·홀수·짝수 구역 나눔은 새 페이지 구역으로 정규화합니다. 메모 작성자·답글 계층은 현재 모델에서 유지하지 않습니다. 변환 문서는 원본과 별도로 검토하세요.

DOCX의 머리글·바닥글 참조가 생략된 구역은 이전 구역의 같은 종류를 상속합니다. 빈 머리글·바닥글을 명시한 구역은 빈 상태를 유지합니다. 가져온 결과는 구역별 값으로 보관되며, Word의 ‘이전과 연결’ 편집 토글은 아직 제공하지 않습니다.

```powershell
npm run build

```

브라우저 테스트는 기본적으로 설치된 Chrome을 사용합니다. 데스크톱 검증은 현재 플랫폼의 Electron을 찾아 별도 사용자 프로필과 합성 문서로 실행하며 실제 PDF의 페이지 수와 미리보기를 비교합니다. 테스트 프로필에 복구 저장 오류를 발생시켜 취소와 사본 저장도 검사합니다. 결과는 `.cache/desktop-smoke-*`에 저장됩니다. 상세 범위는 [VALIDATION.md](VALIDATION.md)를 참고하세요.

## 분석 근거와 범위

REA/Ghidra로 Word 실행 파일의 시작 함수 3개와 WWLIB의 진입점·헬퍼 영역 6개를 분석했습니다. 실행 파일이 WWLIB의 `FMain`으로 제어를 넘기며, WWLIB에는 줄·페이지·글꼴 배치 관련 외부 모듈의 정적 의존성이 있습니다. 이 관찰을 바탕으로 출력 레이아웃·문서 변환·복구 저장을 별도 모듈로 구현했습니다.

WWLIB 전체 분석이나 Word의 내부 편집·조판 알고리즘 복원은 완료하지 않았습니다. 원본 실행 파일, DLL, 디컴파일 결과, 사용자 문서와 로컬 조사 자료는 이 저장소에 포함하지 않습니다. 앱 코드와 종이·연필 아이콘은 독립적으로 작성했습니다.

기반 편집기는 [Tiptap](https://tiptap.dev/), DOCX 생성은 [docx](https://docx.js.org/), 가져오기는 [Mammoth](https://github.com/mwilliamson/mammoth.js)를 사용합니다. Microsoft와 관련 없는 독립 앱입니다.

## Studio 앱 간 표 복사 (1.2.11)

Sheet Studio 0.7.10과 Slide Studio 1.6.1의 표를 홈·표 메뉴 붙여넣기 또는 Ctrl+V/⌘V로 받아 셀을 편집할 수 있습니다. 표 전체를 선택해 복사하면 두 앱으로도 보낼 수 있습니다. 병합·색·글꼴·줄바꿈·표시값을 교환하며, 잘못된 병합이나 한도를 넘는 표는 현재 본문을 바꾸기 전에 거부합니다. [사용법·교환 형식·각 앱 구현 및 제한](https://github.com/beaur8-prog/sheet-studio/blob/main/docs/STUDIO-CLIPBOARD.md)을 확인하세요.

## HWP/HWPX 읽기 (1.3.0)

파일 열기에서 `.hwp`(5.x) 또는 `.hwpx`를 고르면 읽기 화면을 엽니다. 쪽 이동·확대·찾기·전체 텍스트 복사·PDF 저장·인쇄를 지원하며, 원본과 편집 중인 Word 문서는 변경하지 않습니다. **닫기**로 기존 Word 편집에 돌아갑니다. 한글 또는 변환 서버 설치 없이 기기 안에서 처리하며 한국어 대체 글꼴도 포함합니다.

원본과 동일한 조판을 보장하지 않습니다. 공개 샘플 11개를 열었고 암호/구형 샘플 1개는 거부했습니다. 폴라리스 웹 뷰어의 6개 샘플과 한컴 PDF 참고본 3개를 비교했습니다. 긴 취업규칙은 엔진의 표 분할·셀 앞 여백 해석을 수정하여 154쪽에서 폴라리스와 같은 163쪽으로 개선했습니다. Mac 앱의 실제 PDF도 163쪽이며 원문 위치별 문자가 보존되고 종이 높이 밖으로 밀리던 텍스트가 사라졌습니다. 글꼴·일부 페이지 경계·표 테두리 차이는 남습니다. [자세한 검증과 제한](HWP_VALIDATION.md)을 참고하세요. HWP 저장·편집, 암호/DRM, 구형 HWP 3.x는 지원하지 않습니다. 40 MiB·1,000쪽, HWPX 압축 해제 100 MiB 제한을 적용합니다.

[검증 방법·샘플별 차이](HWP_VALIDATION.md). [1.3.0 릴리스](https://github.com/beaur8-prog/word-studio/releases/tag/v1.3.0)의 Mac ZIP·Windows Setup·Linux DEB에 포함됩니다.
